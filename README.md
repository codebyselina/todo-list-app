# todo-list-app
A modern glassmorphism To-Do List web app built with HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Track task progress
- Save tasks using local storage
- Completion animation effects
- Responsive design
- Modern glassmorphism user interface.

## Technologies Used
- HTML
- CSS
- JavaScript
- Font Awesome Icons
